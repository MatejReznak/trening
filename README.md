# Tréningový plán – mama a tato

Stránka: https://matejreznak.github.io/trening/

- `index.html`, `avatars.js` – hotová stránka (GitHub Pages)
- `manifest.json`, `sw.js`, `icon-*.png` – inštalácia na plochu a offline režim
- `src/` – zdrojové časti, `python3 src/build.py` ich spojí do index.html

Denník sa ukladá do súkromného repozitára `trening-data` (súbor `dennik.json`)
cez token vložený v aplikácii v sekcii „☁ Ukladanie“. Token nie je v kóde.
